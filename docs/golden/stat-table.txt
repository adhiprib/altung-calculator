# Editor berkisi. `=` menyimpan sel dan turun satu baris; kolom Y dicapai dengan ►
# lalu ▲ sampai baris pertama, seperti unit fisik (manual hlm. 49). AC memindahkan layar dari
# Statistics Editor ke Statistics Calculation Screen, baru di situ MENU_STAT membuka menu hasil
# (manual hlm. 50). Nomor butirnya dari manual hlm. 49-53: 1:Type 2:Data 3:Sum 4:Var
# 5:Distr pada 1-VAR atau 5:Reg pada jenis berpasangan, 6:MinMax. Submenu Sum 1-VAR adalah
# 1:Σx² 2:Σx, dan submenu Reg A+BX adalah 1:A 2:B 3:r 4:x̂ 5:ŷ.
#

# Format lengkap: docs/golden/README.md
